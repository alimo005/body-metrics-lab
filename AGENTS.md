# AGENTS.md — BodyMetrics Lab

## Project
Free health calculators + "Journal" articles, in English only, for Western readers. Static site on Cloudflare Workers. Domain: bodymetricslab.uk. Revenue plan: Google AdSense (later).

## Stack
Astro (static), TypeScript strict, plain CSS with variables, vanilla TS for calculators. No other frameworks or libraries without explicit approval.

## Structure
- src/pages: routes. src/layouts: page templates. src/components: UI parts.
- src/content/journal: articles as Markdown (one file per article).
- src/calculators: calculator logic, one file per calculator, with tests.
- src/styles: tokens.css and base.css (all colors/fonts/spacing live in tokens).
- legacy/: old site, reference only. Never edit or import.
- DESIGN-SPEC.md: the main design and UX reference. Read it before any UI task.
- CALCULATION-SPEC.md: the scientific specification for the six calculators (Version 1 builds only BMI, BMR & TDEE and Body Fat; the other three are deferred to Version 2) (formulas, constants, categories, ranges, inputs, rounding, reference test cases, sources, UNVERIFIED and HELD items). Read it before any calculator task.

## Health content rules
All numbers, formulas and categories are defined in CALCULATION-SPEC.md. Only items marked VERIFIED, or VERIFIED BY REPRODUCTION, may ship. A feature marked UNVERIFIED or HELD (for example the Miller and Hamwi ideal-weight formulas) is not implemented, and its page stays `noindex` until the owner resolves it. Never label a formula VERIFIED unless its actual source text was checked; a secondary source must be labelled as secondary on the page. Input limits and eligibility rules in CALCULATION-SPEC.md 1.3 are technical or policy boundaries and are never shown as medical limits. Every calculator needs unit tests that reproduce the reference cases in CALCULATION-SPEC.md, and its on-page formula, constants and source links must match that file.

Educational estimates only. No diagnosis, no treatment claims, no fixed calorie plans, no weight-loss promises. Under-20 BMI needs a clear notice (adult categories do not apply; no adult BMI or category is shown). Every number, formula, and category must come from an official or primary source (for example CDC, WHO, NIH, EFSA, the National Academies, FAO, the US Navy guide, or the original paper) and be verifiable. If you cannot verify something, write a TODO and ask me.

### Trust claims (never use)
- "Medically Reviewed", "Clinical Grade", "Clinical Validation", "Peer-reviewed physiological methodology", and any similar unverified claim. No invented reviewers, credentials, institutions, publication or review dates, or statistics.
- Show official source names and links only where the methodology is actually supported by that source.
- BodyMetrics Lab is an educational resource and is not affiliated with or endorsed by CDC, WHO, NIH or any other organisation. Do not use the word "independent" on the site until the owner confirms it reflects the platform's actual ownership and affiliations. State this on the home Sources strip, About, and the calculators index.
- Keep a neutral, evidence-based tone. No hype words ("gold standard", "precision", "biometric engine").
- Do not use images containing fake doctor names, fabricated institutional logos or misleading credentials (see DESIGN-SPEC.md section 12.2). If no suitable image exists, document the missing asset.
