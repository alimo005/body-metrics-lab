# Journal articles

Each article is one Markdown file in this folder; the file name is its web address.

- Start from `_TEMPLATE.md`: copy it, rename the copy, fill it in.
- `draft: true` = hidden everywhere. `draft: false` = published.
- Files that start with an underscore (this file and the template) are never articles.

Full step-by-step instructions (add, preview, publish, unpublish, images, error messages): `docs/PUBLISHING-ARTICLES.md`.
